🏨 Hotel Booking Performance

Project Overview

This project analyzes hotel booking data to identify booking trends, customer behavior, cancellation patterns, and revenue insights using Python, SQL, Excel, and Power BI.

Tools Used

- Python
- SQL
- Excel
- Power BI
- Pandas
- Matplotlib
- Seaborn

Key Analysis

- Booking Trend Analysis
- Cancellation Analysis
- Revenue Analysis
- Customer Segmentation
- Seasonal Performance Analysis

Dashboard Features

- Total Bookings KPI
- Revenue KPI
- Cancellation Rate
- Monthly Booking Trends
- Hotel-wise Performance
- Interactive Filters
